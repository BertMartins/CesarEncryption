# Cifra de César

Criptografa e descriptografa mensagens usando a Cifra de César com chave configurável.

🔗 **Demo:** https://bertmartins.github.io/CesarEncryption/

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 🚀 Como executar

```bash
git clone https://github.com/BertMartins/CesarEncryption.git
cd CesarEncryption
```

Abra o arquivo `index.html` no navegador ou acesse a demo acima.
